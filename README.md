# ANN Binary Classification

## About the Project
This project uses an Artificial Neural Network (ANN) to classify data into two classes using the `make_moons` dataset from Scikit-learn.

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow/Keras

## Steps
1. Load the dataset.
2. Preprocess the data.
3. Split the data into training and testing sets.
4. Build and train the ANN model.
5. Evaluate the model performance.
6. Visualize the results.

## How to Run
1. Open `ANN.ipynb` in Google Colab.
2. Upload the required dataset if needed.
3. Run all the cells.

## Conclusion
This project demonstrates how an Artificial Neural Network can be used for binary classification.
